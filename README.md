# claude-kit

Reusable Claude Code setup: agents, skills and commands.

## Layout
- `agents/`   - who does the work (scan, spec, build, test, refine)
- `skills/`   - how things are done (architecture and doc standards)
- `commands/` - slash commands (/next)

## Install
Run `.\install.ps1` (Windows) to link this repo into `~/.claude`.
